# SovHarn

> Open-Source Agent Harness Platform

## Quick Start

python3 run.py

Then open http://127.0.0.1:8080

## Install

pip install sovharn
sovharn

## Features

- Three-tier memory (Session / Daily / Permanent)
- Spec Engine (YAML-defined output standards)
- Gate Keeper (tool permissions, content safety)
- MCP tool integration
- Clean Web UI

## Data

All data stored locally in `./data/` directory.
